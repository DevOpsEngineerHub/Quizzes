## Question 8
Security Groups are stateful, meaning:

- A. You must create separate inbound and outbound rules for every connection
- B. If inbound traffic is allowed, the response outbound traffic is automatically allowed
- C. They apply only to outbound traffic
- D. They cannot be modified after creation

<details>
<summary>Show Answer</summary>

✅ **Correct Answer: B**

Security groups are stateful — return traffic for an allowed request is automatically permitted, regardless of outbound rules.

</details>

---

## Question 9
How are Network ACLs (NACLs) different from Security Groups?

- A. NACLs operate at the subnet level and are stateless; Security Groups operate at the instance level and are stateful
- B. NACLs and Security Groups are identical in function
- C. NACLs only allow traffic, never deny it
- D. Security Groups operate at the subnet level

<details>
<summary>Show Answer</summary>

✅ **Correct Answer: A**

NACLs are stateless rules applied at the subnet boundary (allow AND deny rules), while Security Groups are stateful and applied per instance.

</details>

---

## Question 10
Can a Security Group have explicit "Deny" rules?

- A. True
- B. False — Security Groups only support Allow rules

<details>
<summary>Show Answer</summary>

❌ **Correct Answer: B**

Security Groups only support Allow rules; anything not explicitly allowed is implicitly denied. Explicit Deny rules exist only in NACLs.

</details>

## Question 12

## Question 14
What is the difference between "stopping" and "terminating" an EC2 instance?

- A. There is no difference
- B. Stopping preserves the instance (and EBS root volume by default) for later restart; terminating permanently deletes the instance
- C. Terminating pauses billing but keeps the instance running
- D. Stopping deletes all attached storage immediately

<details>
<summary>Show Answer</summary>

✅ **Correct Answer: B**

A stopped instance can be started again later and its EBS root volume typically persists; a terminated instance is permanently deleted (unless "Termination Protection" or the volume's delete-on-termination setting says otherwise).

</details>
