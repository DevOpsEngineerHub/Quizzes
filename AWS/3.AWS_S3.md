# AWS S3 Questions 01

## Question 1
What does S3 stand for?

- A. Simple Storage Solution
- B. Simple Storage Service
- C. Secure Storage System
- D. Scalable Storage Server

<details>
<summary>Show Answer</summary>

✅ **Correct Answer: B**

S3 stands for Simple Storage Service, Amazon's object storage service.

</details>

---

## Question 2
S3 is a block storage service, similar to EBS.

- A. True
- B. False

<details>
<summary>Show Answer</summary>

❌ **Correct Answer: B**

S3 is an object storage service, not block storage. Objects (files) are stored with metadata inside buckets, not as raw disk blocks.

</details>

---

## Question 3
What is the top-level container for storing objects in S3 called?

- A. Folder
- B. Bucket
- C. Volume
- D. Partition

<details>
<summary>Show Answer</summary>

✅ **Correct Answer: B**

Objects are stored inside Buckets, which act as top-level containers in S3.

</details>

---

## Question 4
S3 bucket names must be globally unique across all AWS accounts.

- A. True
- B. False

<details>
<summary>Show Answer</summary>

Bucket names are globally unique across all of S3, not just within your own account.

</details>

## Question 5
Is an S3 bucket tied to a specific AWS Region?

- A. True
- B. False

<details>
<summary>Show Answer</summary>

Although bucket names are globally unique, each bucket is created in and physically resides in a specific Region you choose.

## Question 6
What is the maximum size of a single object you can upload to S3 in one PUT operation?

- A. 100 MB
- B. 5 GB
- C. 5 TB
- D. Unlimited

<details>
<summary>Show Answer</summary>

## Question 7

- A. Multipart Upload
- B. Batch Operations
- C. Transfer Acceleration only
- D. Glacier Vault Lock

<details>
<summary>Show Answer</summary>

Multipart Upload splits a large object into parts uploaded in parallel, improving speed and allowing retry of failed parts.

</details>

## Question 10
What is S3 Versioning used for?

- A. Tracking billing changes over time
- B. Keeping multiple variants of an object in the same bucket to protect against accidental overwrite/deletion
- C. Versioning IAM policies
- D. Managing EC2 AMI versions

<details>
<summary>Show Answer</summary>

✅ **Correct Answer: B**

Versioning preserves, retrieves, and restores every version of every object stored in a bucket, protecting against accidental deletes/overwrites.

</details>

---

## Question 11

- A. True
- B. False — it can only be suspended, not disabled

<details>
<summary>Show Answer</summary>

❌ **Correct Answer: B**

Once enabled, versioning can only be suspended, not completely removed from a bucket.

</details>

## Question 12
What happens to an object when it is "deleted" in a version-enabled bucket?

- A. It is permanently removed immediately
- B. A delete marker is added, and the previous versions still exist
- C. It is moved to Glacier automatically
- D. Nothing happens

<details>
<summary>Show Answer</summary>

## Question 25
Which of the following is true about S3's durability?

- A. S3 Standard is designed for 99.999999999% (11 nines) durability of objects
- B. S3 offers no durability guarantees
- C. Durability depends entirely on the customer's own backup strategy
- D. S3 only guarantees durability for Glacier storage classes

<details>
<summary>Show Answer</summary>

✅ **Correct Answer: A**

S3 Standard (and most other classes) is designed for 99.999999999% (11 nines) durability by redundantly storing data across multiple devices and facilities.

</details>
