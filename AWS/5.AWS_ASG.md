## Question 1
What is the primary purpose of Elastic Load Balancing (ELB)?

- A. Encrypting data at rest
- B. Distributing incoming traffic across multiple targets to improve availability and fault tolerance
- C. Storing static website content
- D. Managing IAM permissions

<details>
<summary>Show Answer</summary>

✅ **Correct Answer: B**

ELB automatically distributes incoming application traffic across multiple targets (EC2 instances, containers, IPs) to increase availability and fault tolerance.
