# AWS Global Architecture & Cloud Basics Questions 01

## Question 1
An AWS Region is a physical location made up of multiple isolated Availability Zones.

A. True  
B. False  

<details>
<summary>Show Answer</summary>

✅ **Correct Answer: A**

A Region is a geographic area containing two or more Availability Zones, each with independent power, cooling, and networking.

</details>

---

## Question 2
What is an Availability Zone (AZ)?

A. A single data center with no redundancy  
B. One or more discrete data centers with redundant power, networking, and connectivity within a Region  
C. A global content caching location  
D. A logical grouping of IAM users  

<details>
<summary>Show Answer</summary>

✅ **Correct Answer: B**

An AZ consists of one or more data centers, isolated from failures in other AZs but connected via low-latency links.

</details>

---

## Question 3
Every AWS Region has exactly one Availability Zone.

A. True  
B. False  

<details>
<summary>Show Answer</summary>

❌ **Correct Answer: B**

Every Region has multiple AZs (typically 3 or more) to provide fault tolerance and high availability.

</details>

## Question 4
What is the primary purpose of Edge Locations?

A. Running EC2 instances  
B. Hosting the primary Region infrastructure  
C. Caching content closer to end users for services like CloudFront  
D. Storing IAM policies  

<details>
<summary>Show Answer</summary>

✅ **Correct Answer: C**

Edge Locations are used by services like Amazon CloudFront and Route 53 to cache content and reduce latency for end users.
